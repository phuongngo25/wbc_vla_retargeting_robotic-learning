## 5. ⭐ Khoảng trống tôi nhìn thấy (phần quan trọng nhất của file này)

> Đây là nơi literature map biến thành đề tài. Viết cả những ý còn thô.

| # | Khoảng trống | Bằng chứng nó thật (paper nào cũng thiếu?) | Tôi có làm được không? | Ưu tiên |
|---|---|---|---|---|
| 1 | | | Có / Cần thêm gì | Cao/TB/Thấp |
| 2 | | | | |
| 3 | | | | |

**Ba dấu hiệu của một khoảng trống thật:**

- Nhiều paper **đều giả định** một điều mà **không ai kiểm chứng**.
- Mục "future work" của ≥2 paper độc lập nêu cùng vấn đề.
- Báo cáo tổng kết challenge nêu nó trong phần "limitations".

**Ba dấu hiệu của khoảng trống giả:**

- "Chưa ai thử X trên dataset Y" — thường vì không ai quan tâm.
- "Chưa ai kết hợp A với B" — kết hợp không phải đóng góp nếu không có lý do.
- Bạn tìm chưa đủ kỹ (kiểm tra lại bằng Google Scholar + citations trước khi kết luận).
